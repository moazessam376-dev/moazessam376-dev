# Moaz Essam

I build multi-tenant Postgres with row-level security, agent-team tooling, and automations that took manual work off an operations team.

Portfolio: [https://moazessam.vercel.app](https://moazessam.vercel.app)

## Public repos

- [rls-harness](https://github.com/moazessam376-dev/rls-harness): Cross-tenant row-level-security test harness for Supabase and Postgres: throwaway database, migrations, seeded roles, assertions inside rolled-back transactions.
- [crosstalk](https://github.com/moazessam376-dev/crosstalk): Agents from rival vendors (Claude Code, Codex, Cursor) build one codebase as a team. A review finding is a claim to verify, not a command.
- [WireTrace](https://github.com/moazessam376-dev/WireTrace): Single-file, offline PCAP and router event-log analyzer for support engineers. Runs in the browser; captures never leave the machine.
- [sparring](https://github.com/moazessam376-dev/sparring): Hard technical interviewer and visual tutor for codebases you built with agents: concept-card banks, spaced drills, lessons, mock interviews.
- [solari-lab](https://github.com/moazessam376-dev/solari-lab), [solari-playtest](https://github.com/moazessam376-dev/solari-playtest) and [solari-ci](https://github.com/moazessam376-dev/solari-ci): Python packages for the Solari cloud-browser platform: diagnostics, a playtest agent, and CI sizing.
